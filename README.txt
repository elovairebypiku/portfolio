Files
- index.html: page content and links
- styles.css: design and responsive layouts
- assets/editorial-beauty.webp: hero image

Preview: open index.html in a browser.

Publish with GitHub Pages:
1. Upload index.html, styles.css and the assets folder to the ROOT of your GitHub repository.
2. In GitHub, open Settings > Pages.
3. Under Build and deployment, select Deploy from a branch, then main and /(root), and save.
4. Wait for GitHub to publish your URL.

Before sharing with brands, replace the concept cards with your own photos or videos, and confirm the Instagram link in index.html.
