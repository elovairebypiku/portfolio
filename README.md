# Piku UGC Portfolio

A static beauty, skincare, and lifestyle UGC portfolio designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a new GitHub repository, for example `piku-portfolio`.
2. Upload everything in this folder to the repository root.
3. Open the repository's **Settings**.
4. Select **Pages** under **Code, planning, and automation**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/(root)` folder, then click **Save**.

GitHub will provide the live URL after deployment finishes.

## Edit the portfolio

- Edit `index.html` to change text, links, services, or sections.
- Edit `styles.css` to change colours, typography, spacing, or layout.
- Replace files inside `assets/` to change portfolio imagery.

Before sharing the portfolio with brands, update the Instagram link and add your real UGC videos, business email, and portrait.
